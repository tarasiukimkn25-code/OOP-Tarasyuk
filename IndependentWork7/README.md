# Самостійна робота №8. Узагальнений FIFO-кеш

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

Реалізовано `Cache<TKey, TValue>` з обмеженою місткістю. Значення зберігаються у `Dictionary<TKey, TValue>`, а порядок вставлення — у `Queue<TKey>`. Коли кеш заповнений, новий елемент витісняє найстаріший. Оновлення наявного ключа не змінює його місце у FIFO-порядку.

Реалізовані операції: `Add`, `Get`, `ContainsKey`, `Count`. Для відсутнього ключа `Get` кидає `KeyNotFoundException`, щоб виклик не повернув непомітно значення за замовчуванням.

## Перевірки

`IndependentWork7.Tests` перевіряє додавання й отримання, витіснення найстарішого елемента, виняток для відсутнього ключа, `ContainsKey`, `Count` та поведінку оновлення ключа.

## Як запустити та перевірити

```bash
dotnet run --project IndependentWork7/IndependentWork7.csproj
dotnet test IndependentWork7.Tests/IndependentWork7.Tests.csproj
```

## Контрольні питання

Узагальнений кеш повторно використовує одну реалізацію для різних типів ключа й значення та зберігає перевірку типів компілятором. `Dictionary` забезпечує пошук за ключем, а `Queue` — FIFO-порядок. Якщо відсутній ключ є штатним випадком, замість винятку можна додати `TryGetValue`, який повертає `bool` і значення через `out`.
