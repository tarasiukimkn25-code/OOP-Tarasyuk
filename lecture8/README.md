# Лекція №8. Делегати, анонімні функції та лямбда-вирази у C#

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

У цьому проєкті реалізовано практичні приклади до **Лекції №8**, які демонструють концепції передавання поведінки в мові C#:

1. **Кастомний делегат (`DiscountStrategy`):** Оголошення та використання власного типу делегата для розрахунку знижок.
2. **Системні узагальнені делегати:**
   * `Action<T>` — виконання дій без повернення значення.
   * `Func<T, TResult>` — виконання обчислень із поверненням результату.
   * `Predicate<T>` — перевірка умов (повертає `bool`).
3. **Порівняння синтаксисів:** Анонімні методи (`delegate(...) { ... }`) проти лямбда-виразів (`(...) => ...`).
4. **Робота з LINQ:** Застосування лямбда-виразів для фільтрації та проекції колекцій (`Where`, `Select`).
