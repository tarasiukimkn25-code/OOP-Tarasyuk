# Лабораторна робота №17. Обробка IO/мережевих помилок та патерн Retry (Завантаження зображення)

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

У цій лабораторній роботі реалізовано механізм підвищення відмовостійкості застосунку під час завантаження та читання зображень (Варіант 4) із використанням патерну **Retry** та експоненційної затримки:

* **`RetryHelper.ExecuteWithRetry<T>`:** Узагальнений метод, який виконує передану операцію (`Func<T>`), перехоплює тимчасові винятки, перевіряє їх за допомогою політики `shouldRetry` (`Func<Exception, bool>`) та здійснює повторні спроби зі збільшенням інтервалу очікування ($t = \text{initialDelay} \times 2^{n-1}$).
* **`FileProcessor.ReadImage(string path)`:** Імітує тимчасову недоступність файлу (`FileNotFoundException` під час перших 3 викликів) з подальшим успішним читанням масиву байтів.
* **`NetworkClient.DownloadImage(string url)`:** Імітує тимчасові мережеві збої (`HttpRequestException` під час перших 2 запитів) з успішним завантаженням на 3-й спробі.
* **Вибіркова обробка (`shouldRetry`):** Повторення виконується виключно для `FileNotFoundException` та `HttpRequestException`, тоді як логічні помилки (наприклад, `ArgumentException`) перериваються одразу без марного очікування.
