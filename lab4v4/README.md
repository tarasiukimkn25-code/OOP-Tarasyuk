Temperature.cs — клас, що описує температуру з можливістю збереження значення, вибору одиниці вимірювання (Celsius/Fahrenheit) та переведення між ними.
Program.cs — головний файл із демонстрацією роботи всіх функцій класу Temperature.
Опис реалізації класу Temperature:
Поля та властивості:
Value — значення температури.
Unit — одиниця вимірювання (Celsius або Fahrenheit) із валідацією.
Валідація даних:
Реалізовано перевірку на абсолютний нуль (-273.15°C / -459.67°F). При спробі встановити неприпустиме значення викидається ArgumentOutOfRangeException.
Одновимірний індексатор:
Дозволяє звертатися до значень та одиниць вимірювання за індексом:
[0] або ["value"] — повертає чи змінює значення температури.
[1] або ["unit"] — повертає чи змінює одиницю вимірювання.
Перевантаження операторів:
operator + та operator - : додавання та віднімання температур із автоматичним зведенням до однієї одиниці вимірювання.
operator > , operator < , operator >= , operator <= : оператори порівняння значень температур.
operator == та operator != : оператори рівності з урахуванням перевірок на null.
Додаткові методи та перевизначення:
ConvertTo(string newUnit) — метод для конвертації температури між Цельсієм та Фаренгейтом.
Equals(object obj) — порівняння об'єктів за значенням і одиницею вимірювання.
GetHashCode() — генерація хеш-коду об'єкта.
ToString() — форматоване виведення температури (наприклад, "25.5 °C").
Запуск проєкту:
Для збірки та запуску проєкту виконайте наступні команди у терміналі:
cd lab4v4
dotnet run
