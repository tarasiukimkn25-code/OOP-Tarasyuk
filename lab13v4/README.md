# Лабораторна робота №12. Generic-методи для повторного використання компонентів: Mapper/MaxBy/Reduce з Func/Action

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

У цій лабораторній роботі реалізовано набір узагальнених (generic) функцій вищого порядку у класі `FunctionalUtils` (Варіант 4), що працюють з делегатами `Func<T, TResult>` та обробляють колекції будь-яких типів даних:

* **`Map<T, TResult>`:** Трансформує елементи колекції одного типу в новий тип за допомогою функції-маппера.
* **`Filter<T>`:** Відфільтровує елементи за заданою умовами лямбда-виразу (`Func<T, bool>`).
* **`GroupBy<T, TKey>`:** Групує елементи колекції у `Dictionary<TKey, List<T>>` на основі обраного ключа.
* **`OrderBy<T, TKey>`:** Впорядковує елементи за значенням ключа (`where TKey : IComparable<TKey>`).
* **`ThenBy<T, TKey1, TKey2>`:** Реалізує каскадне сортування (спочатку за первинним ключем, а при їх рівності — за вторинним).

## Переваги Generic-підходу

1. **Повторне використання коду (DRY):** Методи класу `FunctionalUtils` працюють однаково як з призначеними для користувача типами (`Student`), так і з примітивними типами (`int`, `string`).
2. **Типобезпека (Type Safety):** Всі виклики перевіряються під час компіляції без необхідності приведення типів (boxing/unboxing).
3. **Гнучкість:** Передача поведінки через лямбда-вирази дозволяє змінювати логіку без зміни самого методу.
