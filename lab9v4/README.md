# Лабораторна робота №9. Поліморфні сервіси: Notification (DataExporter)

**Тема:** Об'єктно-орієнтоване програмування (C#)
**Виконав:** Тарасюк

## Опис проєкту

У цій лабораторній роботі реалізовано поліморфну систему експорту даних `DataExporter` (Варіант 4), що демонструє ключові поняття поліморфізму, обробки винятків та роботи з колекціями базового типу:

* **Поліморфізм через спадкування:** Абстрактний клас `DataExporter` визначає контракт для експорту. Похідні класи (`CSVExporter`, `JSONExporter`, `XMLExporter`) реалізують специфічну поведінку форматування даних.
* **Валідація та обробка помилок:** Реалізовано перевірку вхідних даних із генерацією власного винятку `ExportException` та безпечною обробкою помилок через блок `try-catch`.
* **Сервісна обробка:** Клас `ExportService` здійснює обхід колекції `List<DataExporter>` із поліморфним викликом методу `Export()` для кожного об'єкта.

## Структура ієрархії класів

**Базовий клас `DataExporter`:**
* Властивість: `FilePath` (шлях до файлу).
* Абстрактний метод: `abstract string Export(List<string> data)` — базова декларація експорту.
* Віртуальний метод валідації: `protected virtual void Validate(List<string> data)` — перевірка даних та шляху.

**Похідний клас `CSVExporter` (CSV експорт):**
* Перевизначений метод: `override string Export(...)` — об'єднує елементи через роздільник `Delimiter`.

**Похідний клас `JSONExporter` (JSON експорт):**
* Перевизначений метод: `override string Export(...)` — форматує список у масив JSON.

**Похідний клас `XMLExporter` (XML експорт):**
* Перевизначений метод: `override string Export(...)` — огортає дані у структуровані XML-теги.

**Сервісний клас `ExportService`:**
* Метод: `void ExportAll(List<DataExporter> exporters, List<string> data)` — поліморфний виклик експорту з обробкою винятків.
