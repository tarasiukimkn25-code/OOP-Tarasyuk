# Лабораторна робота №14. HashSet/Queue/Stack: практичні сценарії (Обробка веб-запитів)

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

У цій лабораторній роботі реалізовано систему симуляції обробки веб-запитів `WebRequestProcessor` (Варіант 4), яка демонструє використання трьох спеціалізованих колекцій під відповідні сценарії:

* **`HashSet<string>` (Унікальні URL):** Забезпечує миттєву перевірку відвіданих адрес та видалення дублікатів з часовою складністю $O(1)$.
* **`Queue<WebRequestData>` (Черга запитів — FIFO):** Моделює чергу надходження та послідовної обробки веб-запитів першим прийшов — першим обробився (`Enqueue`, `Dequeue`).
* **`Stack<string>` (Історія навігації — LIFO):** Моделює функціонал кнопки «Назад» (Back button) у браузері, де остання відвідана сторінка витягується першою (`Push`, `Pop`, `Peek`).

## Особливості колекцій

1. **`HashSet`:** Не зберігає дублікати і не гарантує порядок елементів, але ідеально підходить для індексації та фільтрації унікальних даних.
2. **`Queue`:** Гарантує чесний порядок обробки задач (First In, First Out).
3. **`Stack`:** Забезпечує зворотний порядок доступу до даних (Last In, First Out), що є основою для відміни операцій (Undo) та гісторії дій.
