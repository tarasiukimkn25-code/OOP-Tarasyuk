# Самостійна робота №12. LINQ-процеси для ETL-аналітики продажів

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

Застосунок створює тестові колекції зі 100 товарами, 100 клієнтами та 5 000 продажами. Дані генеруються з фіксованим seed, тому повторні запуски відтворюють той самий набір. Кожен LINQ-запит запускається окремо й вимірюється через власний `Stopwatch`.

1. Топ-3 товари в кожній категорії за загальною кількістю проданих одиниць.
2. Дохід за містами клієнтів після з'єднання продажів, товарів і клієнтів.
3. Кількість одиниць і дохід за роком та місяцем.
4. Складний запит: дохід і кількість за категорією та містом із сортуванням.

## Як запустити проєкт

```bash
cd IndependentWork11
dotnet run
```

Час виконання залежить від процесора й навантаження; у консольному виводі для кожного конвеєра надруковано окреме вимірювання.
