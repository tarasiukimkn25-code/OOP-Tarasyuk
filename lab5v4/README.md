Matrix2x2.cs — клас, що описує квадратну матрицю розміром 2х2 та її математичні операції.
Program.cs — головний файл із демонстрацією роботи всіх функцій класу Matrix2x2.
Опис реалізації класу Matrix2x2:
Внутрішнє сховище:
Приватне двовимірне поле private int[,] _matrix = new int[2, 2].
Двовимірний індексатор:
Реалізовано індексатор this[int row, int col] із getter та setter. Додано перевірку індексів (дозволені значення: 0 та 1), яка викидає IndexOutOfRangeException при виході за межі.
Перевантаження операторів:
operator + : додавання двох матриць елемент за елементом.
operator * : множення матриці на скалярне число, а також скаляра на матрицю.
operator == та operator != : перевантажені оператори рівності та нерівності з урахуванням перевірок на null.
Додаткові методи та перевизначення:
Transpose() — повертає нову транспоновану матрицю (рядки та стовпці міняються місцями).
Equals(object obj) — порівняння об'єктів за значеннями елементів матриці.
GetHashCode() — генерація хеш-коду на основі елементів матриці.
ToString() — зручне форматоване виведення матриці у консоль.
Запуск проєкту:
Для збірки та запуску проєкту виконайте наступні команди у терміналі:
cd lab5v4
dotnet run
