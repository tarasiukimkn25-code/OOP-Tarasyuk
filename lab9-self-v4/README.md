# Самостійна робота №10. Узагальнені методи та делегати

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк | **Варіант:** спільне завдання

## Опис проєкту

Реалізовано статичний клас `CollectionUtils` з узагальненими методами `Map`, `MaxBy`, `Filter` і `ForEach`. Методи приймають стандартні делегати `Func`, `Predicate` та `Action`. У `Program.cs` показано роботу кожного методу з `List<int>`, `List<string>` і `List<Product>`.

## Звіт

**Навіщо делегати в методах-утилітах?** Делегат передає дію в узагальнений метод. Той самий `Map` може перетворювати числа на числа, рядки або інші об'єкти; `Filter` може застосовувати різні умови. Це прибирає дублювання циклів і зберігає типобезпечність.

**Як лямбди спрощують виклик?** Лямбда коротко задає поведінку на місці виклику: `number => number * 2` або `product => product.Price < 2000m`. Для простої операції не потрібно створювати окремий клас чи метод із делегатом.

**Порівняння з LINQ.** `Map` відповідає за призначенням `Select`, а `Filter` — `Where`; LINQ також має `MaxBy`. LINQ зручний і багатий на готові оператори. Власний клас демонструє, як працюють делегати та узагальнення, і може містити специфічні для проєкту правила. `ForEach` залишено окремим методом для демонстрації дії `Action<T>`; для ланцюжків перетворень зазвичай краще використовувати LINQ.

## Приклад результату
