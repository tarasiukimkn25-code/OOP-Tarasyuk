# Лабораторна робота №3. Реалізація паттерну Dispose та керування некерованими ресурсами у C#

**Тема:** Об'єктно-орієнтоване програмування (C#)  
**Варіант:** 4 — Клас `MemoryCache`  
**Виконав:** Тарасюк  

## Опис проєкту
У цій лабораторній роботі реалізовано клас `MemoryCache`, який імітує кеш у пам'яті та демонструє правильне використання паттерну `Dispose` (`IDisposable`) для звільнення керованих та некерованих ресурсів.

## Основні можливості класу MemoryCache
* **Поля:**
  * `_cacheData` (`Dictionary<string, string>`) — збереження кешованих даних.
  * `_isActive` (`bool`) — прапорець стану активності ресурсу.
  * `_disposed` (`bool`) — відстеження стану звільнення ресурсів.
* **Методи:**
  * `Set(key, value)` — додавання/оновлення запису в кеші.
  * `Get(key)` — отримання значення за ключем.
  * `Dispose()` — примусове або автоматичне очищення кешу та деактивація ресурсів.

## Демонстрація роботи (у Main)
1. **Конструкція `using`:** автоматичний виклик `Dispose()` при виході з блоку.
2. **Явний виклик `Dispose()`:** ручне очищення ресурсів після завершення роботи.
3. **Робота деструктора:** автоматичне очищення незакритих ресурсів через `GC.Collect()` та `GC.WaitForPendingFinalizers()`.
