# Лабораторна робота №18. Власні винятки та патерн Result (Банківський сервіс)

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

У цій лабораторній роботі реалізовано систему обробки фінансових операцій `BankService` (Варіант 4), що демонструє два підходи до обробки помилок у C#:

1. **Власні винятки (Custom Exceptions):**
   * **`InsufficientFundsException`** — містить додаткові властивості `CurrentBalance` та `AttemptedAmount` для деталізації помилки нестачі коштів.
   * **`AccountBlockedException`** — містить властивість `AccountNumber` та сигналізує про спробу доступу до заблокованого рахунку.
2. **Патерн `Result<T>`:**
   * Узагальнений клас із властивостями `IsSuccess`, `Value`, `Error` та статичними фабричними методами `Success(T)`, `Failure(string)`, `Failure(Exception)`.
   * Застосовується у методах `TryTransfer` та `FindAccount` для обробки очікуваних бізнес-помилок (невірний номер рахунку, перевищення балансу) без витрат продуктивності на розкручування стеку винятків (`try-catch`).

## Порівняння підходів

* **Власні винятки** доцільно застосовувати для виняткових, нештатних ситуацій (порушення інваріантів, блокування безпеки), які не повинні виникати під час нормального потоку виконання.
* **Патерн `Result<T>`** ідеально підходить для валідації вхідних даних, пошуку елементів та очікуваних бізнес-відмов, роблячи контракт методу явним і безпечним.
