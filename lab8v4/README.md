# Лабораторна робота №8. Поліморфізм: динамічне зв’язування та перевизначення методів

**Тема:** Об'єктно-орієнтоване програмування (C#)  
**Виконав:** Тарасюк  

## Опис проєкту

У цій лабораторній роботі реалізовано ієрархію класів `Animal` → `Mammal` / `Bird` (Варіант 4), що демонструє ключові поняття поліморфізму:

* **Динамічне зв'язування та перевизначення (`override`):** Клас `Mammal` перевизначає віртуальний метод `Breathe()`, забезпечуючи поліморфну поведінку при виклику через посилання базового типу `Animal`.
* **Приховування методів (`new`):** Клас `Bird` використовує модифікатор `new` для приховування методу базового класу, що вимикає поліморфізм при виклику через посилання `Animal`.
* **Агрегація результатів:** Обхід колекції `List<Animal>` із викликом методів та підрахунком (агрегацією) кількості екземплярів кожного типу.

## Структура ієрархії класів

* **Базовий клас `Animal`:**
  * Властивість: `Name` (назва тварини).
  * Віртуальний метод: `virtual void Breathe()` — базова реалізація дихання.
* **Похідний клас `Mammal` (Ссавець):**
  * Перевизначений метод: `override void Breathe()` — специфічне дихання ссавців.
* **Похідний клас `Bird` (Птах):**
  * Прихований метод: `new void Breathe()` — дихання за допомогою легень та повітряних мішків.
