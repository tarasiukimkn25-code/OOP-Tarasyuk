## Опис проєкту
У цій лабораторній роботі реалізовано клас `Teacher`, що демонструє основні принципи ООП:
- Інформаційну закритість (інкапсуляцію) через приватні поля та власні властивості.
- Валідацію вхідних даних (стаж викладача не може бути від'ємним).
- Перевантаження конструкторів (виклики через `: this()`).
- Використання деструктора (фіналізатора) та примусовий виклик збирача сміття (`GC.Collect()`).

## Структура класу Teacher
* **Приватні поля:** `_name`, `_subject`, `_experienceYears`.
* **Властивості:** `Name`, `Subject`, `ExperienceYears` (з перевіркою коректності значення).
* **Конструктори:**
  * За замовчуванням: задає базові значення через виклик параметризованого.
  * Параметризований: приймає ім'я, предмет та стаж.
* **Метод `Introduce()`:** виводить інформацію про викладача в консоль.
* **Деструктор `~Teacher()`:** сповіщає про вивантаження об'єкта з пам'яті.
