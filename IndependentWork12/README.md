# Самостійна робота №13. Паралельні обчислення з LINQ і PLINQ

**Тема:** Об'єктно-орієнтоване програмування (C#) | **Виконав:** Тарасюк

## Опис проєкту

Застосунок порівнює час одного й того самого CPU-насиченого обчислення в LINQ та PLINQ на 1, 5 і 10 мільйонах випадкових значень. Для кожного розміру виводяться час, відношення швидкостей і перевірка однакового результату.

Друга частина демонструє втрату оновлень під час паралельного `counter++`, повторює сценарій тричі й виправляє його атомарним `Interlocked.Increment`.

## Як запустити проєкт

```bash
cd IndependentWork12
dotnet run
```

Час залежить від кількості ядер, обладнання та інших процесів. На малому наборі витрати на розподіл роботи можуть зробити PLINQ повільнішим; на обчислювально насиченому наборі він може прискорити обробку.
